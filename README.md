# Grade Estimator
## Description

The Grade Estimator is a Python application that calculates a student's final course grade using assignment information stored in tasks.json and student scores provided in a CSV file.

The application calculates and displays the total points earned, overall percentage, and corresponding letter grade.

## Project Files
GradeEstimator_1702625.py — Main Python application.
tasks.json — Contains assignment information.
grades_0.csv — Sample student grades file.
grades_50.csv — Sample student grades file.
## Requirements
Python 3.x
All project files listed above must be in the appropriate project directory.
## How to Run
Download or clone the repository to your computer.
Open a terminal or command prompt in the project folder.
Run the following command:
   python GradeEstimator_1702625.py

When prompted, enter the name of the grades file you want to use.

Input:

Enter the grades file: grades_0.csv

Example 2: Using grades_50.csv

Input:

Enter the grades file: grades_50.csv


## Output format:

Total Points: ...
Percentage: ...
Letter Grade: ...


Note: The ellipses represent calculated values. Actual results depend on the assignment configuration in tasks.json and the scores in the selected CSV file.

## Application Output

The program displays the following information:

Total Points: The total points earned by the student.
Percentage: The student's overall grade as a percentage.
Letter Grade: The letter grade corresponding to the calculated percentage.
## Purpose

This application provides a convenient way to estimate a student's final course grade using assignment data and recorded scores.
